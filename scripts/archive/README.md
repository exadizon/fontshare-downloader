# Archive - retired pre-clean-break scripts

These flat root-level scripts predate the canonical CLI and are kept only
for history. They are not maintained.

Use instead:

- `python cli/download.py` - download all Fontshare families
- `python cli/install.py` - install extracted fonts
- `python scripts/sync_catalog.py` - refresh `data/fonts.json`

None of the files in this directory are imported by the canonical code.
