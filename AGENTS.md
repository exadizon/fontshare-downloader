# fontshare-downloader - Agent Instructions

Use `gh-axi` for GitHub and `chrome-devtools-axi` for browser automation.

## Project overview

Fontshare (fontshare.com, a free-fonts service from Indian Type Foundry) offers
high-quality fonts but no bulk download. This repo solves that with two parts:

1. **Python CLI** (`cli/`) - canonical bulk downloader + cross-platform font
   installer. Discovers the live catalog from
   `https://api.fontshare.com/v2/fonts`, downloads each family ZIP from
   `https://api.fontshare.com/v2/fonts/download/<slug>`, extracts immediately
   into `downloads/fonts/<slug>/`, optionally installs desktop fonts.
2. **Web UI** (`web/`) - Next.js + TypeScript + Tailwind catalog browser that
   copies Fontshare aesthetics (paper background, ink text, grotesk display
   type, minimal grid). Static catalog data from `data/fonts.min.json`,
   live previews via Fontshare CDN CSS API, per-family direct downloads,
   multi-select bulk queue. Deployable to Vercel, also runs via `npm run dev`.

Catalog size: ~100 families (verified Sept 2026 via live API
`count_total: 100, has_more: false`). Rich per-family metadata: category,
designers, tags, styles/weights, variable axes, OpenType features, license
(`itf_ffl` or `sil_ofl`).

## Repo layout

```
AGENTS.md / CLAUDE.md / README.md / prd.md
cli/
  download.py        # canonical downloader (live catalog, extract, retry)
  install.py         # canonical installer (user|system scope, Win/macOS/Linux)
  import_zips.py     # import browser-downloaded *_Complete.zip files
  archive.py         # shared, zip-slip-safe family ZIP extraction
  requirements.txt
data/
  fonts.json         # full live metadata, generated by scripts/sync_catalog.py
  fonts.min.json     # slim UI bundle consumed by web/lib/fonts.ts
scripts/
  sync_catalog.py    # regenerates data/ from the live API
  archive/           # retired legacy scripts (pre-clean-break era)
web/                 # Next.js App Router UI (see web/AGENTS.md if present)
docs/demo/           # screenshots, demo GIF
downloads/           # runtime output, NEVER committed (gitignored)
```

Pre-clean-break legacy flat scripts (`fontshare_downloader*.py`,
`simple_downloader.py`, `discover_fonts.py`, `debug_downloader.py`,
`install_system_fonts.py`, etc.) are retired to `scripts/archive/` and are
not maintained. Do not add new root-level Python scripts.

## Commands

```bash
# Sync catalog (regenerates data/fonts.json + data/fonts.min.json)
python scripts/sync_catalog.py

# Download all fonts
python cli/download.py
python cli/download.py --output-dir ./downloads --rate-limit 1.0 --max-concurrent 3 --verbose

# Download + install in one step
python cli/download.py --install --install-scope user

# Install already-downloaded fonts
python cli/install.py --scope user
python cli/install.py --fonts-dir ./downloads/fonts --scope system

# Import browser-downloaded family ZIPs (stdlib only) and install
python cli/import_zips.py --install            # scans ~/Downloads
python cli/import_zips.py --source ./zips --dry-run

# Web UI
cd web; npm install; npm run dev      # local
npm run lint; npm run build           # verify before commit
```

## Conventions

- Never use the em dash. Use a plain dash "-" instead.
- Commit incrementally: inspect `git status`, `git diff`, `git log --oneline -10`
  before each commit; stage only intended files; never commit secrets.
- Never add agent name as co-author; never mention AI authorship.
- Never manually edit CHANGELOG.md or auto-generated files.
- `downloads/` output is gitignored. Never `git add` ZIPs or binaries.
- `data/fonts*.json` is generated. Regenerate via `scripts/sync_catalog.py`,
  do not hand-edit slugs.
- Downloads link to `https://api.fontshare.com/v2/fonts/download/<slug>`.
  Previews use `https://api.fontshare.com/v2/css?f[]=<slug>@<weights>&display=swap`.
- Be respectful to Fontshare: default rate limit 1.0s, max 3 concurrent.
- Reproduce bugs E2E (real API call, single-font download) before fixing.
- Prefer quality, simplicity, robustness and long-term maintainability over
  dev cost. Fix lint/test flakes seen along the way.
